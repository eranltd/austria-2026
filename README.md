# austria-2026

לוח תכנון לטיול משפחתי באוסטריה והונגריה — מסלול יומי, בנק אטרקציות, ומסעדות לפי אזור.

**חי כאן:** https://eranltd.github.io/austria-2026/

---

## מה יש בפנים

| מסך | מה הוא עושה |
|---|---|
| **מסלול דינאמי** | הלוח — מה מתוכנן לכל יום, ומה בחלופות |
| **סדר יום** | הפירוט היומי: לינה, ארוחות, קניות, לוגיסטיקה |
| **אוסטריה** | 106 מקומות, מקובצים לפי אזור |
| **בודפשט** | 26 מקומות, לפי מרחק הליכה מהמלון |

**בנק אטרקציות** (כפתור בראש) פותח את כל המאגר עם סינון לפי אזור וסוג.
**התאריכים שלי** מזיז את כל הטיול לתאריכים אחרים ומחשב מחדש את ימי השבוע.

## איך זה בנוי

קובץ HTML אחד, בלי תלויות ובלי שלב בנייה. הנתונים מוטמעים בתוכו.

```
index.html               האפליקציה כולה — HTML, CSS, JS ונתונים
manifest.json            הגדרות PWA
sw.js                    service worker — עבודה בלי אינטרנט
icon-*.png               אייקונים
.nojekyll                אומר ל-GitHub Pages לא להריץ Jekyll
```

## עבודה בלי אינטרנט

אחרי פתיחה אחת מקוונת האפליקציה נפתחת גם בלי קליטה — רלוונטי בהרים ובנסיעות.

הדף עצמו נטען **קודם מהרשת** ורק אז מהמטמון, כדי שעדכון שנדחף לכאן יגיע מיד
ולא ייתקע אצל אנשים בגרסה ישנה. אחרי שינוי משמעותי כדאי להעלות את
`CACHE_VERSION` בתוך `sw.js` — זה מנקה מטמון ישן אצל כולם.

## התקנה כאפליקציה

- **iPhone / iPad:** שיתוף ← «הוספה למסך הבית»
- **Android / Chrome:** תופיע הצעת התקנה

## שמירה

השינויים נשמרים ב-`localStorage` — כלומר **על המכשיר שפתח אותם בלבד**.
אין שרת ואין סנכרון: מה שאחד משבץ, אחר לא רואה.

## עריכה

לשנות נתונים (אטרקציות, ימים, מסעדות) — לערוך את בלוק `const DATA` בתוך
`index.html`. אין שלב בנייה; שומרים, דוחפים, ו-Pages מפרסם.
